# 🛒 Maven Market — Retail Analytics & Power BI Dashboard

## 📌 Project Overview
This repository contains an end-to-end Power BI data analysis project for **Maven Market**, a multi-national grocery retail chain operating across the United States, Mexico, and Canada. 

The goal of this project is to model multi-year transaction data (1997–1998), analyze customer demographics, track product category profitability, monitor store performance, and build an interactive executive dashboard.
